# TripWise backlog

The following features are intentionally deferred beyond the MVP:

- Live multi-user collaboration and presence
- Push notifications
- QR invite scanning
- Receipt OCR
- Automatic exchange-rate provider
- PDF/Excel export
- Paid subscriptions and advertising
- Production AI features

The current schema and feature services keep identifiers and ownership boundaries suitable for these later additions. No current UI presents them as available.
